# Integral account requests — operator review draft

This is a proposed operational procedure, not an approved service commitment or
evidence of a completed deletion drill. V75 Inc. and support@v75inc.com are the
confirmed operator/contact. Assign a responsible operator before launch.

1. Receive the request privately through the support contact. Identify whether it
   concerns the online Integral account, a hosted Business workspace or local One
   files. Account identity does not confer Business workspace access or authority
   over a local installation.
2. Authenticate current control of the requested account using an approved Clerk
   sign-in/verification path. Do not ask for passwords, API keys or session tokens
   in support mail, chat or public GitHub issues. An email address or screenshot
   alone is not proof of account control.
3. Record the request, verified canonical issuer/subject, requested scope and
   operator decision in a restricted case. Verify the exact production instance
   and account in Clerk before any action. Retain only the necessary evidence.
4. For access/correction, use Clerk's reviewed administrative or user-account flow.
   Avoid exporting unrelated accounts, tokens or other users' information. Any
   delivery of personal information requires an authenticated private destination.
5. For online deletion, confirm the exact irreversible action and account scope
   with the requester, then use the approved provider flow. Verify the result.
   Record the documented provider backup/retention limitations and any applicable
   legal exception; do not promise an unverified global erasure deadline.
6. Explain that an online account deletion does not remove local One data or
   revoke its durable offline setup. Never issue a remote workspace deletion or
   rotate the local account binding as part of online account support. A user can
   continue local access/export and separately manage their own files/backups.
7. Close the case through the authenticated private route, retaining only the
   approved minimal operational record. Apply the reviewed case-retention policy.

Before launch, run this procedure against a clearly designated test account,
verify export/correction/deletion boundaries and retained offline access, and
record the operator, dates and results privately. No production account is to be
deleted merely to create release evidence. Provider/transfer arrangements,
retention schedules, exception handling and any response deadlines need explicit
operator/legal approval in [privacy readiness](PRIVACY-READINESS.md).
